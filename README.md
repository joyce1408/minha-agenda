# Minha Agenda V5 — versão independente

Agenda pessoal local, publicada no GitHub Pages.

- Sem Google Calendar
- Sem Apple Calendar
- Sem Microsoft 365 / Teams
- Sem APIs externas ou servidor próprio
- Dados de compromissos, tarefas e lembretes armazenados localmente no navegador
- Sem dados de demonstração quando o armazenamento local estiver vazio
- Funciona offline depois da primeira abertura, usando Service Worker para cache local
- Indicadores de prazo calculados pela data/hora atual do aparelho
- Backup manual em JSON para exportar e importar os dados
- Exclusões com confirmação explícita
- Layout responsivo para iPhone, sem rolagem horizontal
- Navegação móvel em uma única linha com Agenda, Tarefas, Lembretes e Ajustes

## Link definitivo

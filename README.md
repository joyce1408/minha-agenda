# Minha Agenda V2

Primeiro protótipo visual/funcional criado do zero.

## O que já funciona
- Agenda Dia / Semana / Mês
- Criação de compromissos
- Lista de próximos compromissos
- Tarefas com conclusão
- Lembretes rápidos
- Painel de conexões Apple / Google / Microsoft
- Configurações de aparência
- Salvamento local no navegador
- Layout responsivo para iPhone, iPad e computador
- PWA básico

## O que ainda não está conectado
As integrações reais com Apple, Google e Microsoft/Teams precisam de autenticação e APIs oficiais. Este protótipo não simula login nem armazena tokens.

## Estrutura
- `index.html` — telas
- `styles.css` — layout
- `app.js` — lógica local
- `manifest.webmanifest` — PWA
